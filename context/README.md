# spike-html-hosting-components

spike-html-hosting-components is the documentation components layer of spike-html-hosting. It
is planned to hold the section tree, page header, site index, and cross-site navigation, on
spike-html-apps-foundation as a peer, released by tag and pinned by every site. Until its first
component, its check is Prettier, shellcheck, and actionlint, and package.json stays at `0.0.0`,
which `release.yml` never tags. This context records only working knowledge the code and the
README do not express.
