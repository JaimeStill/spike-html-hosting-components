# spike-html-hosting-components

The documentation components layer of spike-html-hosting: the web components the repositories'
GitHub Pages sites and hosted artifacts are built from, published as
`@jaimestill/spike-html-hosting-components` on top of
[spike-html-apps-foundation](https://github.com/JaimeStill/spike-html-apps-foundation).

It holds no components yet and is unreleased: its first release is v0.1.0. Until then
package.json's version is `0.0.0`, and the release workflow cuts no tag.

- `mise run install`: install the pinned tools and node_modules.
- `mise run check`: the check.
- `mise run currency`: report every pin behind its latest.
