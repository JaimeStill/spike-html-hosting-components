# spike-html-hosting-components

The documentation components layer of spike-html-hosting, published as
`@jaimestill/spike-html-hosting-components` with
[spike-html-apps-foundation](https://github.com/JaimeStill/spike-html-apps-foundation) as a peer.
It is planned to hold the web components the spike's GitHub Pages sites build their pages from:
the section tree, page header, site index, and cross-site navigation.

It holds no components yet. package.json's version stays `0.0.0`, which the release workflow
never tags, until the first release, v0.1.0.

- `mise run install`: install the pinned tools and node_modules.
- `mise run check`: the check.
- `mise run currency`: report every pin behind its latest.
